# Angry Birds — Android (WebView + Canvas)

Полноценная 2D-игра в стиле Angry Birds: рогатка, физика, разрушаемые блоки, 50 уровней,
магазин, достижения и настройки. Отрисовка — Canvas 2D внутри WebView, нативная обёртка —
`MainActivity` на Java (ландшафт, immersive-фуллскрин).

## Как получить APK

1. Открой вкладку **Actions** в этом репозитории.
2. Выбери последний запуск **Build APK** (зелёная галочка = сборка прошла).
3. Внизу страницы, блок **Artifacts** → скачай **angry-birds-apk**.
4. Распакуй zip → внутри файл `app-debug.apk`.
5. Установи на телефон, разрешив установку из неизвестных источников.

## Структура

- `app/src/main/assets/index.html` — интерфейс: меню, уровни, магазин, достижения, настройки, HUD.
- `app/src/main/assets/game.js` — движок: физика, уровни, птицы, экономика, звук.
- `app/src/main/java/com/cim/angrybirds/MainActivity.java` — WebView, ландшафт, скрытие панелей.
- `.github/workflows/build.yml` — автосборка APK (Gradle 8.7 + JDK 17).

## Что умеет игра

| Раздел | Детали |
|:---|:---|
| Уровни | 50 штук, 6 типов построек, рост сложности, разблокировка по цепочке |
| Птицы | Красная, жёлтая (ускорение), синяя (раскол на три), чёрная (взрыв) |
| Материалы | Дерево, лёд, камень — своя прочность и цвет |
| Магазин | Синяя птица, бомба, золотая птица ×3, супер-таран ×3, кладовая ×2 |
| Достижения | 20 штук с прогресс-барами и наградой 200 монет |
| Настройки | Звук, музыка, вибрация, сброс прогресса |
| Прогресс | Звёзды (до 150), монеты, сохранение в localStorage |

## Управление

- Потяни птицу на рогатке пальцем назад и отпусти — выстрел.
- Тап по экрану во время полёта — способность птицы.
